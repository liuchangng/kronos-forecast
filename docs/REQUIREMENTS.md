# Kronos A 股预测面板 需求文档

> 本文件是需求与约束的权威记录。需求变更时同步更新，并标注版本。

版本：v1.0（2026-08-04）

## 1. 背景

基于开源金融 K 线基础模型 **Kronos**（45+ 交易所数据预训练，AAAI 2026），构建一个本地 A 股预测面板。
用户通过浏览器选择股票，实时拉取行情，用 Kronos-base 模型预测未来走势并可视化。

## 2. 用户场景

1. 打开本地 Web 面板（Gradio）
2. 一键点击「淳中科技」或「剑桥科技」快速预测
3. 或输入任意 A 股代码（如 600519），点「添加并预测」
4. 等待约 1 分钟，看到预测图、数据表、涨跌摘要
5. 调整预测天数重跑

## 3. 功能需求

### FR-1 股票池
- FR-1.1 内置淳中科技（603516）、剑桥科技（603083）
- FR-1.2 支持输入任意 A 股代码（自动识别沪深前缀）
- FR-1.3 支持动态添加股票到下拉列表（会话内）

### FR-2 数据
- FR-2.1 腾讯行情接口拉取日线，后复权，价格恒为正
- FR-2.2 最多 2000 行，回看最近 400 个交易日
- FR-2.3 失败重试 3 次，超时 15s

### FR-3 预测
- FR-3.1 使用 Kronos-base + Tokenizer-base，CPU 推理
- FR-3.2 默认预测 60 个交易日，可调（10-120）
- FR-3.3 涨跌停限幅 ±10%
- FR-3.4 输出 open/high/low/close/volume/amount 全字段

### FR-4 界面
- FR-4.1 深色科技风主题（深蓝黑 + 霓虹青/紫）
- FR-4.2 展示：历史+预测价格对比图、预测数据表、摘要卡片（当前价/预测价/涨跌幅/区间高低）
- FR-4.3 预测进行中显示进度状态
- FR-4.4 图表美观：科技感配色、网格、图例清晰

### FR-5 文档
- FR-5.1 需求文档（本文件）
- FR-5.2 进度文档 `docs/PROGRESS.md`，记录每一步完成情况与遗留问题

## 4. 非功能需求

| 编号 | 项 | 要求 |
|------|----|------|
| NFR-1 | 性能 | base 模型 CPU 预测 60 步 ≤ 90 秒 |
| NFR-2 | 兼容 | Windows 10+，Python 3.12，纯 CPU |
| NFR-3 | 可维护 | 逻辑层（predictor.py）与 UI 层（app.py）分离 |
| NFR-4 | 可扩展 | 股票池用字典驱动，加股票只改一行 |
| NFR-5 | 隐私 | 全本地，数据仅从公开行情接口拉取，无上传 |

## 5. 明确不做（非目标）

- 多股票并行预测
- 历史回测 / 收益归因
- 持仓管理与交易信号
- 模型微调 / 在线学习
- 云端部署

## 6. 风险与对策

| 风险 | 影响 | 对策 |
|------|------|------|
| 腾讯接口变动 | 无法拉数据 | 接口参数集中在 predictor.py，单点替换 |
| HF 模型下载慢/失败 | 无法加载模型 | 走 hf-mirror 镜像；模型缓存后无需再下 |
| CPU 推理慢 | 体验差 | 显示进度；默认 60 步 ≤90s 达标 |
| 涨跌停限幅截断 | 预测失真 | 结果中标注是否被截断 |
| Kronos 仓库非 pip 包 | 依赖脆弱 | 复制 `model/` 到项目内，冻结使用 |

## 7. 验收标准

1. `uv run app.py` 启动成功，浏览器可访问
2. 点击淳中科技，1.5 分钟内输出图表 + 表格 + 摘要
3. 输入 600519 等自定义代码可预测
4. 界面深色科技风，无文字溢出/布局错乱
5. 需求与进度文档齐全且与实际一致
